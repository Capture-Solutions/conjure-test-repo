## 🌟 About

This repository was conjured into existence purely for testing. It ships with a delightful little **Hello, World!** program — guaranteed to compile and run on the first try.

## 🚀 Quickstart

Clone it:

```bash
git clone https://github.com/Capture-Solutions/conjure-test-repo.git
cd conjure-test-repo
```

Run it:

```bash
python hello.py
```

Expected output:

```
👋 Hello, World!
✨ The magic works.
```
